# 02 · 去广告：AyraHikari/openclash_adguard

补上底座停用掉的广告过滤。AdGuard / EasyList 规则转成 Clash classical 格式，上游每 12 小时自动更新。

## 接入

`config/rule-providers.yaml` 里已经写好了 `adguard_allow` 和 `adguard_block` 两个 provider，直接合并进配置即可。

## 顺序要求（重要）

OpenClash 不支持在单个规则集里写例外，所以白名单和黑名单是两个文件，**引用顺序必须是 allow 在前、block 在后**：

```yaml
rules:
  - RULE-SET,adguard_allow,DIRECT
  - RULE-SET,adguard_block,REJECT
```

顺序反了会导致该放行的也被拦截。

## 内存取舍（重要）

默认配置（`config/rule-providers.yaml`）的去广告黑名单用 oisd small（**5.6 万条 / 2.1MB**，每天自动更新），256MB 内存的路由器（如 Redmi AX3000）无压力。

内存充足时可用完整版 `config/rule-providers-full.yaml`：黑名单换成 `adguard_block`（**27.4 万条 / 10.7MB**），拦截更全但启动慢、常驻多占几十 MB 内存。两个版本二选一，不要同时用。
