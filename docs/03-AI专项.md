# 03 · AI 专项：rorojiao/clash_rules

50+ 家 AI 服务域名规则（ChatGPT、Claude、Gemini、Grok、Perplexity、Cursor、GitHub Copilot 等），每天自动更新。解决"AI 站点域名变得快、通用规则跟不上"的问题。

## 基础接入

`config/rule-providers.yaml` 里的 `ai-services` provider（behavior: domain，每天更新一次），规则引用：

```yaml
rules:
  - RULE-SET,ai-services,AI服务
```

确保 `proxy-groups` 里有 `AI服务` 分组（底座模板自带的可直接用）。

## 进阶：链式代理（dialer-proxy）

想让 AI 流量单独走一条干净出口（例如美国原生 IP，而日常流量走香港/日本）时用：

```yaml
proxies:
  # 前置中转：ISP 只看到到这里的连接
  - name: "Front-Relay"
    type: ss
    server: relay.example.com
    port: 443
    cipher: chacha20-ietf-poly1305
    password: "xxx"

  # AI 出口：经由前置中转出去，AI 服务看到的是这个 IP
  - name: "AI-US"
    type: vmess
    server: us.example.com
    port: 443
    uuid: "xxx"
    dialer-proxy: "Front-Relay"

proxy-groups:
  - name: "AI服务"
    type: select
    proxies:
      - "AI-US"
      - "Front-Relay"
```

把示例里的 `relay.example.com` / `us.example.com` / 密码换成你自己的节点。完整示例见上游 `config/example-full.yaml`。
