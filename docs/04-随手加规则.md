# 04 · 随手加规则：Zeral-Zhang/openclash-helper

浏览器插件，管"长尾"：再全的规则库也有覆盖不到的冷门站，遇到分流不对的网页，右键一点就加规则，不用进路由器翻配置。

## 两种模式

| 模式 | 规则存哪 | 特点 |
|---|---|---|
| 路由器同步 | 路由器本地文件 | 简单，局域网访问 |
| 云端同步 | Cloudflare KV | 跨设备，OpenClash + Clash Verge 通用，需部署 Worker |

插件会自动在 OpenClash 里建 `OpenClashHelper_Proxy` / `OpenClashHelper_Direct` 两个 UCI 配置并刷新规则集。

## 使用

1. 在任意网页右键 →「添加到直连规则」/「添加到代理规则」。
2. 「规则管理」里可分组查看、删除、导出；支持 WebDAV 备份（含密码等敏感信息，用私有 WebDAV）。

## 要求

路由器需安装 `luci-mod-rpc` 和 `luci-compat`；云端模式需先部署 Cloudflare Worker。
